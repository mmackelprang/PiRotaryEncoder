# PiRotaryEncoder — brand guide

**Proposed display name:** PiRotaryEncoder
**Tagline:** *Knobs, at kernel speed.*

## Why this name

Kept — kernel modules are found by exact name. Visual sibling of KnobKey (RotaryUsb): same knob, this one shows the signals.

## The mark

A knob above its own quadrature: the A/B square waves that interrupt handler decodes.
